# MeishiLink

日本向け Web 名刺共有・管理アプリ。閲覧は登録不要。登録ユーザーが自分の Web 名刺を作成し、QR で共有する。

## 課題仮説

紙名刺の管理難 (紙が溜まる / 検索不可 / デジタル入力面倒 / vCard 手入力)。紙からデジタルへの架け橋を狙う。

## ターゲット

- 日本の社会人
- 交換した名刺が多く、管理が追いついていない人

## 機能 (MVP = P0 + P1)

### P0
- ユーザーが情報を登録 → Web ページに名刺を表示
- フォント等のカスタマイズ
- QR コードでシェア・交換
- 閲覧者が情報を連絡先アプリに保存できる (vCard)
- 連絡先をアプリ内に保存し、一覧性高く管理 (閲覧者側、登録不要)

### P1
- 追加情報をモーダル等で表示
- アクセスログ集計
- テンプレートパッケージ
- 印刷機能

### 非機能
- 閲覧にユーザー登録は不要

## 画面項目

### 1. トップ名刺画面
氏名 / 会社名 / 部署名 / 役職 / 会社の電話番号 / メールアドレス / 会社住所 / 会社ロゴ / サイトリンク

### 2. 拡張領域
ポエム / プロファイル / SNS リンク

## スタック (確定)

| 項目 | 採用 |
|---|---|
| Framework | Next.js (App Router) |
| ORM | Prisma |
| DB | better-sqlite3 (SQLite) |
| Auth | Auth.js v5 (Magic Link + Google) |
| 画像保存 | ローカル volume にファイル |
| 閲覧者側保存 | localStorage / IndexedDB |
| デザイン方向性 | ミニマル・モダン |
| デプロイ | Coolify (Docker)。MVP はローカル動作 |
| 本番URL | `meishi.appily.run/<handle>` |

## 規約

- handle は変更不可。ただし大小文字・句読点揺れは同一視 (NFKC + lowercase で正規化)
- 閲覧は登録不要
- MVP の DoD: P0 + P1 全機能がローカルで動くこと
